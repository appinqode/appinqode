Colorette

Generate color palettes, extract colors from images, create tints and shades, build design system and mesh gradients.

Read the Privacy PolicyRead the Terms of Use
Colorette brings together everything you need to build professional color workflows in a single application. Generate random color palettes, create structured tints and shades, extract colors from images, create design systems, design interactive mesh gradients, and export production-ready assets for SwiftUI, Xcode, web development, and design projects. Whether you're building an app, creating a design system, developing a brand identity, or experimenting with new ideas, Colorette helps you move from inspiration to implementation faster.

Generate random color palettes.
Instantly create unique palettes containing 4 to 8 colors. Perfect for UI design, branding, illustrations, prototypes, and creative inspiration. Fine-tune every generated color using the built-in color picker and instantly copy color values for development. Export your palettes as CSV, or Xcode .colorset file.

Build tints and shades.
Start with any HEX color and automatically generate balanced lighter and darker variations. Create semantic color scales, accessibility-friendly themes, and consistent design systems with just a few clicks. Export your palettes as CSV, or Xcode .colorset file.

Extract colors from images.
Import PNG, JPG, JPEG, HEIC, TIFF, or WebP images and automatically extract their dominant colors. Turn photos, screenshots, illustrations, logos, and artwork into reusable color palettes ready for your next project. Export your palettes as CSV, or Xcode .colorset file.

Create design systems.
Generate beautiful, harmonious color palettes for UI/UX, web, and app design. Create palettes with 4 to 8 colors, choose from 20 curated palette styles and multiple color harmony modes, then export your palettes as CSV, CSS, or Xcode .colorset file. Each color is automatically assigned a semantic role, making it easy to build consistent, reusable design systems.

Design SwiftUI mesh gradients.
Create beautiful mesh gradients visually with an interactive editor. Adjust mesh points, customize every color, and preview your design in real time. Export the mesh gradient as Swift, CSV or PNG file.

Export your work in formats ready for production:
• Copy colors as HEX, RGBA, and SwiftUI Color code;
• Export palettes as CSV files;
• Export palettes as CSS files;
• Import previously saved CSV palettes;
• Export Xcode .colorset assets (Dark Mode and Light Mode) compatible with Asset Catalogs;
• Automatically generate Dark Mode color variants for exported assets;
• Export standalone Swift files for mesh gradient views.

Iconset Kit

Create complete AppIcon asset catalogs for macOS, iOS, iPadOS, and watchOS from a single image. Fast, simple, and ready for Xcode projects.

Read the Privacy PolicyRead the Terms of Use
Iconset Kit is a simple and efficient utility for Apple developers and designers who need to create App Icon asset catalogs for Xcode. Instead of manually resizing images and preparing dozens of icon variations, Iconset Kit generates all required app icon sizes from a single source image and exports a ready-to-use .appiconset folder. Simply select an image, preview the generated icons, and export the asset catalog directly into your project. Perfect for independent developers, students, hobbyists, and professional teams building apps for Apple's platforms.

Supported Platforms and Features.
Generate App Icon asset catalogs for macOS, iOS, iPadOS, and watchOS. All icon sizes required by Xcode are automatically generated and organized in a valid asset catalog structure.
- Create complete App Icon asset catalogs from a single image;
- Generate all required icon sizes automatically;
- Export ready-to-use .appiconset folders;
- Drag and drop image support;
- Quick image selection using the native macOS file picker;
- Preview generated icon sizes before export;
- Simple and lightweight interface;
- Native SwiftUI experience designed for macOS;
- No subscriptions, no account or internet connection required.

Designed for Developers.
Preparing app icons is one of the final steps before publishing an app, but it can quickly become repetitive and time-consuming. Iconset Kit removes the manual work by creating all required icon sizes and organizing them into an Xcode-compatible asset catalog structure. Whether you are building a new application, updating branding, testing multiple icon concepts, or preparing assets for App Store submission, Iconset Kit helps streamline the process.

Easy Workflow.
- Select or drag an image into the app;
- Supported files: .png, .jpg, .tiff, .psd, .avif, .heic, .webp, .ai, .svg;
- Preview the icon;
- Choose an export location;
- Generate the asset catalog;
- Drag the generated .appiconset folder into Xcode.

Melobar puts your music right in your Mac's menu bar. Listen to your local music collection without opening a large music app or interrupting your workflow. See your music.

- Previous and next track;
- Shuffle;
- Repeat song or playlist;

- Playlist management;

Mopperase

Clean up old development data. Reclaim disk space. Browse Derived Data, Archives, Installed Platforms, and iOS Device Support, to manage outdated files.

Read the Privacy PolicyRead the Terms of Use
Reclaim valuable disk space by clearing out old development data generated by Xcode. Keep your Mac running at its best. Mopperase is the smart and simple macOS utility built for Apple developers who want to keep their machines clean, fast, and organized. Over time, Xcode silently accumulates large amounts of cached data, archived builds, device support files, installed platforms, and derived data that can consume tens - sometimes hundreds - of gigabytes of storage. Finding and safely removing these files manually is tedious, confusing, and time consuming, so Mopperase makes Xcode storage management effortless. With a clean, intuitive interface, Mopperase lets you explore, analyze, sort, and remove unnecessary Xcode generated files in just a few clicks, helping you recover precious disk space and keep your development environment optimized.

Mopperase shows you exactly which Xcode directories use the most storage:
- Derived Data: Inspect cached build artifacts, indexes, and temporary project data;
- Archives: Review stored app archives and remove outdated builds;
- Installed Platforms: Manage downloaded SDK platforms no longer needed;
- iOS Device Support: Delete legacy device support files created by older iOS versions.

Smart sorting and filtering.
Quickly locate exactly what you want to clean. Filter and sort contents by Name, Size, and System Version. Whether you're looking for the largest files, the oldest platform versions, or a specific project cache, Mopperase helps you find it instantly.

No more digging through hidden system folders or guessing what's safe to remove. Every directory is presented with detailed information so you can make informed cleanup decisions:
- Delete individual items;
- Select multiple items for batch deletion;
- Remove everything inside a directory at once.
